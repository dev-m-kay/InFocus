Simple attention Tracker



#### Milestone 1

Implemented prototyping use a tutorial. Did basic usage of MediaPipe and OpenCV to track the gaze direction of the user.

#### Milestone 2

Prototyping different methods of eye tracking to the display. Usages of the pure data of the face mesh and calculations or some other method were tested. Also begun using PyQt for the interface.

#### Milestone 3

Starting to integrate the UI and gaze tracker. Getting away from prototyping and starting to finish the gaze tracking implementation. Made sure that PyQT and OpenCV functions together correctly. Made the screens the settings of the application.

#### Milestone 4

Finished implementing the gaze tracking with a statistical model and calibration. Implemented the off-screen detection and sound alarm. Also implemented the excluded look away areas. Additional UI element is the overlay to make full screen calibration and visual alarm.
